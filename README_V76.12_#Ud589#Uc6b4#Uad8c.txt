2026 경덕 ALL PLAY 체육한마당 V76.12 — 행운권 추첨 탭

[추가 기능]
- 학생 행운권 탭 추가
- 응모기간: 2026.9.24.(목) ~ 9.30.(수)
- 학번 + 이름 + 개인 4자리 PIN 최초 설정
- 이후 학번 + 이름 + PIN으로 재접속
- 1인 1상품 / 마감 전 상품 변경 가능
- 상품별 실시간 응모자 수 표시
- 관리자: 학생 검색, PIN+응모 초기화, 상품별 현장 무작위 추첨
- 당첨 시 대형 화면용 당첨 연출

[상품 10종]
농구공 / 축구공 / 배구공 / 셔틀콕 1타(12개입) / 고급 스포츠양말 / 과자박스 /
올리브영 1만원권 / 짜장면 2인권 / 와플대학 1만원권 / 우리 반 강당 1시간 대관권

[설치]
1) supabase_lucky_setup.sql 내용을 Supabase SQL Editor에서 1회 실행
2) 수정된 index.html, app.js를 기존 GitHub 웹앱 파일에 덮어쓰기
3) 기존 styles.css/config.js/이미지/assets 등 나머지 파일은 그대로 유지
4) 브라우저 캐시가 남으면 강력 새로고침

[중요]
- PIN 초기화는 관리자 탭 > 행운권 관리·추첨에서 합니다.
- 초기화 시 해당 학생의 기존 응모도 함께 삭제되며 학생이 다시 PIN을 설정합니다.
- 이 기능은 학교 행사 편의를 위한 간단 인증 방식입니다. 고위험 개인정보/보안 용도로 사용하지 마세요.
