기존 경덕 웹앱 버전의 레이아웃을 이어받지 않고 새로 작성한 버전입니다.

## 주요 탭
- 홈
- 일정
- 실시간 점수
- 경기 규칙
- 대진·기록
- 참가자
- 학급 깃발
- 운영·심판
- 신청곡
- 사진·영상
- 본부 게시판
- 교직원

## 경덕 계획서 반영
- 2026.10.1 08:30~16:00
- 학년별 순환경기
- 8자 줄넘기 / 슈팅 릴레이 / 바운드 배구 / 2인 3각
- 달리는 줄다리기 / 미션 이어달리기 / 이어달리기
- 축구·피구 사전경기
- 학급 깃발 및 응원 퍼포먼스
- 학년별 점수 구조

## 중요
현재 프로토타입 데이터는 localStorage에 저장됩니다.
