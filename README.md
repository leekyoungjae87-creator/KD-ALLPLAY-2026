# 경덕 ALL PLAY PWA

이 버전은 브라우저에서 열리는 사이트가 아니라, 배포 후 휴대폰 홈 화면에 설치 가능한 PWA(Progressive Web App)입니다.

## 포함 기능
- 모바일 반응형
- 홈 화면 설치
- 오프라인 캐시
- 일정 / 실시간 점수 / 경기요강 / 학급깃발 / 신청곡 / 공지 / 관리자
- 당일 현재 프로그램 자동 표시
- 로컬 관리자 데모

## 배포
GitHub Pages, Netlify, Vercel 등에 이 폴더 전체를 올리면 됩니다.
PWA 설치 기능은 HTTPS 환경에서 정상 동작합니다.

## 현재 한계
점수·공지·신청곡 데이터는 현재 브라우저 localStorage 기반입니다.
여러 기기에서 동일 데이터를 공유하려면 Supabase/Firebase 같은 실시간 백엔드 연결이 필요합니다.
