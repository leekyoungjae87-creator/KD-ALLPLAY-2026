기존 경덕 웹앱 버전의 레이아웃을 이어받지 않고 새로 작성한 버전입니다.

## 주요 탭
- 홈
- 일정
- 실시간 점수
- 경기 규칙
- 대진·기록
- 참가자
- 학급 깃발
- 운영·심판
- 신청곡
- 사진·영상
- 본부 게시판
- 교직원

## 경덕 계획서 반영
- 2026.10.1 08:30~16:00
- 학년별 순환경기
- 8자 줄넘기 / 슈팅 릴레이 / 바운드 배구 / 2인 3각
- 달리는 줄다리기 / 미션 이어달리기 / 이어달리기
- 축구·피구 사전경기
- 학급 깃발 및 응원 퍼포먼스
- 학년별 점수 구조

## 중요
현재 프로토타입 데이터는 localStorage에 저장됩니다.

### Supabase 연결 순서
1. Supabase에서 새 프로젝트를 만든 뒤 `supabase_vote_setup.sql` 전체를 SQL Editor에서 1회 실행합니다.
2. Project Settings > API에서 Project URL과 anon public key를 복사합니다.
3. `config.js`의 `url`, `anonKey` 두 값을 채운 뒤 `config.js`까지 GitHub Pages에 함께 업로드합니다.
4. 관리자 전용 > 교직원 투표 관리에서 투표를 시작합니다.
5. 교직원은 웹앱 > 교직원 전용에서 이름과 비밀번호로 입장해 학년별 1표씩 투표합니다.
