## v2 변경사항
- 체육한마당 느낌을 강화한 스포츠 동작 배경 및 역동적 메인 비주얼
- 메인 화면에 계획서 기준 종목별 배점표 추가
- 교직원 투표 탭 제거
- 학급 깃발 갤러리 탭 추가
- 관리자 화면에서 학급 깃발 이미지 등록 가능
- 관리자 화면의 테스트 비밀번호 안내 문구 제거

## v3 변경사항
- 메인 배경을 이모지 중심에서 실제 스포츠 동작을 표현한 일러스트 장면으로 전면 교체
- 달리기, 줄넘기, 농구, 배구, 줄다리기 동작을 한 화면에 배치
- 운동장 트랙과 축제 깃발 요소 추가
- 모바일에서도 메인 텍스트 가독성 유지


## 최신 v4
- 응원 퍼포먼스 포스터의 크림/네이비/그린/오렌지/옐로우 컨셉으로 UI 강화
- `교직원 투표` 탭 복원 및 교직원 전용 비밀번호 화면 적용
- 교직원 투표 안에 `학급 깃발 투표` + `학급 응원 퍼포먼스 평가` 구성
- 학급 깃발 사진은 관리자 메뉴에서 등록, 교직원 투표 화면에서 확인
- 응원 퍼포먼스 평가 기준: 참여도·협동성·창의성·완성도·호응도 각 20점
- 비밀번호는 화면에 표시하지 않음
- 현재 투표/사진 데이터는 브라우저 localStorage 기반. 여러 교직원 기기 집계는 Supabase 연동 필요


## V4 상단 배경 수정본
- V5 구조는 사용하지 않고 V4 기능/화면 구성을 그대로 유지했습니다.

- 사용자가 첨부한 ALL PLAY 스포츠 축제 화면의 상단 배너 영역을 웹용으로 적용했습니다.
- 교직원 투표(학급 깃발 + 응원 퍼포먼스), 관리자, 배점표 등 V4 기능은 그대로 유지됩니다.
