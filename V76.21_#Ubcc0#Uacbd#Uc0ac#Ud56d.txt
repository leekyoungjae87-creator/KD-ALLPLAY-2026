V76.21 행운권 응모완료 + 관리자 대시보드

[학생 화면]
- 응모 완료 후 '🎫 나의 행운권' 카드 표시
- 학번 + 마스킹 이름 표시
- 현재 응모 상품 / 해당 상품 현재 응모 인원 표시
- '9월 30일 23:59까지 응모 상품 변경 가능' 안내
- 상품 변경 시 나의 행운권이 즉시 갱신
- 학번 4자리 숫자(예:1234)로 정리
- 상품 카드: 'OOO 현재 응모 인원 N명' 표시

[관리자 화면]
- 전체 응모 인원
- 미응모 추정 인원(전교생 600명 기준)
- 응모율
- PIN 등록 후 상품 미선택 인원
- 상품별 현재 응모 인원 / 당첨 인원 / 추첨 상태
- 학번·이름 검색
- PIN 초기화
- 응모 명단 최종 확정
- 명단 확정 전 추첨 차단
- 상품별 당첨자 추첨
- 당첨 결과 저장 및 새로고침 후 유지

※ '미응모 추정'은 전교생 기준값 600명을 사용합니다.
※ 현재 PIN 초기화 방식은 기존 응모 정보도 함께 초기화합니다.
